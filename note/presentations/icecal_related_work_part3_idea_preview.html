ICE-CAL / METHOD IDEA 01

精确修正 = 真机系数 × 归一化修正量

执行失配不改变修正的方向，只改变需要的剂量。归一化修正量 Δzᵢ 事先在仿真训练好并冻结；部署时真机数据只用来读出一个标量系数 ĉ，经实测映射 σ 换算成剂量，乘上冻结的修正量。真机不更新任何权重。

z̄ = z + Σᵢ σᵢ(ĉᵢ) · Δzᵢ
Δzᵢ · 归一化修正量—仿真训练：方向 + 满刻度基准，冻结 ❄，真机不重训
ĉᵢ · 真机系数—部署时从 30 帧 State/Action 历史读出的比率，真机唯一需要提供的东西
σᵢ(ĉᵢ) · 剂量换算—实测映射：读数是几成 → 该上几倍修正量
z̄ · 校准后 latent—送入冻结的 Tracker Decoder 生成动作
真机数据的角色变了：不是微调的训练集，而是校准的读数。
ICE-CAL / METHOD IDEA 02

方向、比率、换算表

同一个增益故障，看三个量各自承担什么。

Δzᵢ

基准修正向量

位置

Latent Add：加进 Tracker Decoder 前的 latent

输入

仿真 rollout：注入已知强度 c_true 的单轴故障 → 初始化 Δzᵢ，z+Δzᵢ 送入 Tracker → 反解得到 a_true → 监督学习训练 Δzᵢ

输出

单一原因的 Δzᵢ

c

故障比率 · 在线读数

位置

部署分支的 Coefficient Encoder

输入

30 帧 State/Action 历史（与 Tracker 同一份缓冲）

输出

比率 ĉ ∈ [−1,1]³：故障是满刻度的几成；50 Hz 每步一次，c=0 ≡ 标称

σᵢ

读数 → 剂量 · 实测映射

位置

Latent Add 之前、读数之后：查表换算

输入

读数 ĉ（横轴是读数，不是真值）

输出

剂量倍数 σ(ĉ)，乘上 Δzᵢ 施加

ΔZᵢ 怎么算出来 · 解析反解
g·a* = a → a* = a/g （一步除法）
延迟 k 拍 → 提前 k 拍发 （一步平移）
a* − b = a → a* = a + b （一步加法）
C 怎么读出来 · 增益轴
发 10 动 9  ·  发 20 动 18  ·  发 5 动 4.5
比率恒 0.9
Σ 怎么测出来 · 真机逐档试补
读数 0.30 → 0.32 倍
读数 0.55 → 0.60 倍 ← 试补发现 0.6 才最稳
读数 0.85 → 0.95 倍
真机成本：单轴 ≈ 7,500 步 ≈ 2.5 分钟（5 点 × 2 次 × 15 s @50 Hz）· 三轴 ≈ 7.5 分钟 · 零训练
修正 = σ(c) · Δzᵢ：c 读出"几成"，σ 换算"该上几倍"，Δzᵢ 提供方向与满刻度基准。
ICE-CAL / METHOD IDEA 03

部署：读比率 → 查表 → 沿基准方向修正

Coefficient Encoder 从最近 30 帧 State/Action 历史读出比率 ĉ；查冻结的 σᵢ 换算剂量；沿冻结方向 Δzᵢ 修正 latent。它不生成 Action；冻结的 Tracker Decoder 仍然是唯一的动作生成器。

Output：nominal latent z

Output：calibrated latent z̄
→
Tracker Decoder ❄Input：z̄
Output：6-step Action
→
Execute Action[0]只执行动作块的第一个 Action
30-step historyState / Action 短历史
→
Coefficient Encoder输出比率 ĉ ∈ R³
→
Frozen σᵢ读数 → 剂量查表
→
Direction BankΣσᵢ(ĉᵢ)Δzᵢ
Identity condition: ĉ = 0  →  z̄ = z  →  原始 Tracker 路径保持不变。
ICE-CAL / METHOD IDEA 04

方向、系数和标尺
不能一起学习

三个对象承担不同职责。联合训练会让它们互相补偿，最后无法解释。ICE-Cal 每个阶段只保留一个可训练 owner，其余对象冻结。

STAGE 1 / DIRECTION

Learn Δzᵢ

使用已知 c_true 注入 latent。冻结 Planner 和 Tracker，只更新当前故障轴的方向。

compensated / uncompensated error ≤ 0.1
→ normalize and freeze
STAGE 2 / COEFFICIENT

Learn ĉ

冻结所有方向。从 30 帧历史读出故障系数，不允许网络直接生成动作。

|ĉ − c_true| ≤ 0.05
→ freeze Coefficient Encoder
STAGE 3 / SCALE

Fit σᵢ

不训练神经网络。扫描单轴强度，拟合单调 PCHIP 曲线并输出可审计证书。

R² ≥ 0.95 + monotonicity
→ freeze Scale Curve Bank
Direction → Coefficient → Scale   /   strictly serial, no joint training
