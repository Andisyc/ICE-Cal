# ICE-Cal 方法总结（供评审）

> 状态：方法设计讨论稿。Stage 1 结构化算子修订（方案 C）尚未获授权实施；
> 本文档仅供设计评审，不代表已验证的实验结论。

## 一句话定位

在冻结的追踪策略上，将执行失配的补偿分解为"逐轴标定基 × 在线读出系数 × 真机实测换算"，
实现可验证、可组合、逐台可校准的 sim2real 执行校准，策略全程不重训。

## 核心 Insight

参数化执行故障对动作的扭曲是与指令内容无关的恒定标量：

- 增益故障：实际执行幅度 / 指令幅度 恒定（发10动9、发100动90）；
- 延迟故障：执行滞后固定拍数；偏置故障：执行偏移固定量。

因此每类故障的严重程度可由单一标量 c（相对预设满刻度归一化，c=0 ≡ 标称）完整刻画，
修正量 = 总量（c=1 时的全部修正）× 比例 c。

理论根基（不需自建理论，引用即可）：

- 刚体动力学对物理参数线性（Slotine & Li 1987；Atkeson, An & Hollerbach 1986）：
  sim2real 失配 = Δθ 生活在有限维参数空间；一阶意义下执行误差对 Δθ 线性 → 组合可加；
- 自适应逆动力学控制范式（在线估计参数误差 → 补偿）是 c/σ/修正链的祖先；
- 低维性间接证据：RMA 系小维 context 向量、SimOpt（arXiv:1810.05687）、
  BayesSim（RSS'19）、DR 短随机化清单的工程实践。

## 三要素

- **c（系数读数）**：Coefficient Encoder（2 层 Transformer，d_model=128）从 30 帧
  State/Action 历史每步输出 m 个系数；非零系数即"哪个原因、几成"，
  无需事先知道原因集合。
- **Δᵢ（逐轴修正算子，Stage 1 学习并冻结）**：统一写成 Δᵢ(z)=Mᵢ·z+bᵢ
  （gain→M 主导；offset→b 主导；delay→移位 M）。
  注：原版"每轴固定向量"经离线几何诊断证实对 gain 轴函数类不足
  （逐样本可解残差~1e-11；共享方向补偿比仅 0.81/0.85；方向不共线，
  top1 能量 0.28~0.30）——根因：线性 Decoder + 加性修正只能产生
  状态无关的 action 修正，而 gain 补偿须正比于指令。
  结构化算子（方案 C）为当前待批准修订。
- **σᵢ（真机标定曲线）**：读数→实际剂量的单调 PCHIP 映射；真机逐档试补测得
  （判据：补偿后残余读数归零），单轴 5 点×2 次×15s ≈ 2.5 分钟，
  三轴 ≈ 7.5 分钟，零训练。

## 部署链路

z̄ = z + Σᵢ σᵢ(ĉᵢ)·Δᵢ(z)（latent 唯一注入点）→ 冻结 Tracker Decoder → 6 步 action chunk，
receding-horizon 执行第一步。c=0 时与原策略逐比特一致。
未枚举故障：不可命名，但残余读数不归零可检测；|c|>1 显式超量程报警。

## 三层架构（讨论后修订版）

1. **离线（仿真，多样性免费）**：枚举参数化故障 → 伪逆算修正方向（诊断工具复用）
   → SVD/PCA 提基 + 谱图（低维性证据；方法即经典 ROM/POD 惯例）→ 学 Δᵢ、ĉ、σ。
2. **在线（部署）**：Encoder 读系数 c → 查 σ → 沿基修正（现状不变）。
3. **运维（真机，慢变量）**：收集补偿后残余 → PCA → 发现新显著方向即扩基（冻结）、
   并可用真机数据更新 σ——"基在仿真里出生，在真机上生长"。
   （与迭代学习控制 ILC 同族，划界：ILC 逐次迭代面向重复任务；我们每步在线读数。）

## 三阶段串行训练（禁联合训练）

- S1：注入已知满刻度故障，a* 解析可算（a/g、提前k拍、a−b），
  min‖π(z+c_true·Δᵢ(z))−a*‖²，学成冻结；验收：补偿后误差 ≤ 未补偿 0.1。
- S2：L = ‖ĉ−c_true‖² + 0.1·动作一致性（系数为主监督），门限 |ĉ−c_true| ≤ 0.05。
- S3：c∈[−1,1] 21 点 × 32 rollouts 扫描，单调 PCHIP 拟合 σ，R² ≥ 0.95。

## 相对 SplitAdapter（arXiv:2606.03297）的对比

- 其修正映射由 RL 在随机化分布上训练并冻结：平均最优、不可逐因验证、
  真机不一致只能重训、latent 无真值锚点（真机 26/27；6kg OOD 单一 latent 18/30）。
- ICE-Cal：逐轴可验证（c_true 监督）、组合靠加法（不用赌外推）、
  逐台几分钟标定（平均最优→逐台最优）、越界显式报警。
- 待验证性能假设（非已证结论）：① 残差精度（轨迹偏差/倾斜/放置误差）更优；
  ② 训练未见的故障组合下性能缓坡 vs 悬崖；③ 多台个体上性能方差更小。

## 相似工作版图（"总量拆分量"）

- Task Arithmetic（ICLR'23, arXiv:2212.04089）：权重空间"方向×系数再相加"，结构同构；
  差异：离线权重编辑 vs 我们 latent 空间 + 在线物理读数 + 真机标定曲线。
- RMA（RSS'21, arXiv:2107.04034）：单一 latent 黑盒适配（我们不分解的对立面）。
- Residual RL（arXiv:1812.03201）：base+残差叠加，单体学习、无逐因分解。
- 经典控制：增益调度 / 系统辨识 / 鲁棒控制不确定性模型（三轴分类法的理论祖先）。

## 中心声明（claim）的定位

不声称"三根轴覆盖世界"；声明：**学习型追踪策略的真机执行失配实践中是低维的**——
绝大部分失败模式落在少数参数化方向（及其组合）张成的子空间内。
覆盖程度是平台相关的可测量量（残差谱分析 + 部署中残余监测），不是先验公理。
领域内 baseline（DR/RMA/SplitAdapter）均未证明覆盖，且其覆盖失败是静默的；
我们提供留出组合评测 + 显式越界报警，可审计性高于现有标准。

## 已知边界（主动声明）

1. 枚举成本：每轴需先写故障代数（拿真值的前提，任何监督方法均有此成本）；
   轴库是工具性载体，不声称世界清单。
2. 适用范围：补偿在 latent 上局部线性的参数化故障；非线性切换类故障出界。
3. 超量程（|c|>1）：线性外推不可信；设计上量程选宽 + 报警降级。
4. c 误归因风险：未建模故障可能被错记到某根轴；残余检测可报警但不可纠偏。
5. σ 标定假设故障在标定期间稳定存在、大剂量试探不失稳；需安全包络设计。
6. 方法对 Decoder 结构敏感（线性 head 下 gain 固定向量已被证伪）；
   非线性 Decoder 下结论需消融。
7. gain 轴原版固定向量已被诊断证伪；结构化算子修订待批准后实施与复测。

## 评审关注的关键实验（优先级排序）

1. 低维性谱图：枚举故障修正方向的 SVD 谱（离线）+ 真机残差谱（部署）；

3. 族外故障行为图：摩擦/背隙注入下的误读→报警→降级；
4. Decoder 结构消融（线性 vs 非线性）。
