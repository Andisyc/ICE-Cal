# Current Impact Rules

Any change to axis meaning, analytic target, Direction Bank shape/normalization, coefficient input or
output, stage loss/ownership, scale mapping, composition order, event fallback, schema, or first-action
consumer impacts v007/v006 semantics and requires Module Test Card review.

Changes to H/K/D, Tracker checkpoint identity, deployment entrypoint, effective fault grid, or curve
artifact invalidate downstream module/formal evidence. Historical v006/v005 tests cannot close these
impacts.
